# Spring Framework Lab

Ten independent Spring Boot practical experiments.

## Experiments
1. Spring Framework Setup and Hello World
2. Spring Modules: Core, JDBC and MVC
3. Auto Wiring and Logging
4. AOP @Before Advice
5. Spring Data JPA CRUD
6. Pagination and Sorting with JPA
7. RESTful Web Service CRUD
8. SOAP Web Service and WSDL
9. Simple REST Controller CRUD
10. @RequestBody and ResponseEntity

## Requirements
- Java 17+
- Maven 3.9+
- IntelliJ IDEA recommended
- Postman for REST
- SoapUI for SOAP

## Run
Open any Week folder in IntelliJ, wait for Maven to load, then run its WeekXXApplication.java.

Or from that folder:
mvn spring-boot:run

## Git
git add Week-01-Spring-Setup
